# Power BI Healthcare Analytics Dashboard
Developed an interactive Power BI dashboard for healthcare analytics, focusing on providing key insights into patient demographics, clinical performance and operational metrics.
The dashboard aggregates data from various sources, offering a comprehensive view of patient admissions, discharge rates and service utilization.
By enabling real-time filtering and data slicing, it supports stakeholders in identifying trends and improving decision-making.
